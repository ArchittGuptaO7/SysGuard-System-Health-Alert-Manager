// what it watches

Ten things SysGuard keeps an eye on

Every check reads straight from the kernel — no agents, no daemons, no polling services to babysit.

Samples /proc/stat twice, one second apart, and computes real load from the delta — not a snapshot guess.

Memory Monitoring

Reads MemTotal and MemAvailable from /proc/meminfo and reports used/total in GB with a live percentage.

Network Status

Lists active interfaces with ip -brief addr, then pings 8.8.8.8 to confirm real internet reachability.

System Uptime

Converts /proc/uptime seconds into a plain-English "X days Y hours Z minutes" readout.

Counts and lists active sessions with who — useful context whenever a spike coincides with someone logging in.

Alert Generation

Fires a memory alert automatically once usage crosses an 80% threshold, emailed via standard Unix mail.

Log Reports

Every run writes a timestamped .txt report to ./reports/, with an optional PDF export via enscript + Ghostscript.

Bash Automation

A single menu-driven script with set -o errexit and pipefail — safe to run unattended or drop into cron.

Lightweight Performance

Zero third-party runtimes, zero background daemons — just core coreutils and awk, so the monitor never becomes the load.

Project Workflow

1

Start

Menu boots, error handling armed, ./reports created if missing.

2

Collect System Data

Reads /proc/stat, /proc/meminfo, /proc/uptime, df, and who.

3

Analyze Resources

Computes CPU delta, memory percentage, and disk utilization from raw samples.

4

Compare Thresholds

Each metric is colour-graded: green under 50%, yellow under 80%, red above.

5

Generate Alerts

Memory over 80% triggers a mail-based alert with hostname and timestamp.

6

Store Logs

Report written to reports/report_YYYYMMDD_HHMMSS.txt, optional PDF export.

7

Display Results

Colour-coded summary printed straight to the terminal for immediate reading.

# Reads /proc/meminfo and returns used | total | percent
get_memory_info() {
  mem_total_kb=$(awk '/MemTotal/ {print $2}' /proc/meminfo)
  mem_avail_kb=$(awk '/MemAvailable/ {print $2}' /proc/meminfo)
  mem_used_kb=$((mem_total_kb - mem_avail_kb))
  mem_percent=$(awk -v u="$mem_used_kb" -v t="$mem_total_kb" \
    'BEGIN{printf "%.1f", (u/t)*100}')
  printf "%s|%s|%s\n" "$mem_used_gb" "$mem_total_gb" "$mem_percent"# Colour-grades a percentage: green < 50, yellow < 80, red above
colorize_usage() {
  val=$1
  if (( $(echo "$val < 50" | bc -l) )); then
    echo -e "${GREEN}${val}%${NC}"
  elif (( $(echo "$val < 80" | bc -l) )); then
    echo -e "${YELLOW}${val}%${NC}"
  else
    echo -e "${RED}${val}%${NC}"
  fi
}
